03 카테고리별 스킬 매트릭스

문제 유형별로 어떤 스킬을 켜면 되는지 한눈에 짚기 위한 6구획. 각 셀은 카테고리의 대표 스킬 2–3개와 그 강점을 요약.

Process · 개발 리듬

일하는 방법을 잡는 스킬

ROI 최상위. 결과물 품질보다 "다음 한 걸음을 어떻게 정할지"를 규율화한다.

  • Test-Driven Development /tdd실패 테스트가 먼저 존재해야만 구현이 가능. 코드 커밋 게이트로 작동한다.
  • Brainstorming /brainstorm기능 착수 전에 의도·요구·설계를 명확히 하는 인터뷰 루프. 스코프 드리프트 예방.
  • Writing Plans /write-plan2–5분 단위 태스크로 쪼갠 실행계획을 산출. 서브에이전트 실행과 궁합.
Quality · 진단 · 리뷰

버그와 리뷰 미스를 줄이는 스킬

기능이 붙은 뒤 문제를 잡는 게 아니라 문제가 커지기 전에 재현하고 리뷰한다.

  • Systematic Debugging /debug4단계 근본원인 프로토콜. 추측 기반 수정 금지 규칙이 명시적으로 걸림.
  • Code Review /code-reviewdiff에만 집중, 발견은 카테고리+파일·라인으로 리포트. 노이즈가 적다.
  • Security Review /security-reviewOWASP·크리덴셜·프롬프트 인젝션 관점의 감사 체크리스트.
Design · UI · 문서 시각화

보이는 결과물의 격을 올리는 스킬

"AI가 만든 티"를 없애고 판단이 담긴 시각 결과물을 만든다. 발표·랜딩·리포트에 유효.

  • Frontend Design /frontend-design주제에 맞는 팔레트·타이포·레이아웃을 매번 새로 설계. 클리셰 차단.
  • Artifact Design + DiagrammingClaude Artifact를 한 장 페이지·인포그래픽 수준으로 끌어올리는 프리로드.
  • DataViz차트·대시보드 컴포넌트에서 색·주석·엔드포인트 강조까지 규범화.
Docs · 파일 산출

실제 파일을 만드는 스킬

본문 설명이 아닌 열리는 파일. 리포트·계약서·발표자료 자동화 파이프라인의 뼈대.

  • PDF · DOCX · XLSX · PPTXAnthropic 공식. 추출·편집·서식·수식·차트까지 파이썬으로 처리.
  • Fill Form / Sign / Annotate계약·양식 자동화. PDF 뷰어 스킬과 결합해 흐름형 작업.
  • Make PDF마크다운을 인쇄 품질 PDF로. 표지·목차·워터마크·페이지 번호.
Ops · 세션 · 토큰

긴 작업을 지속가능하게 만드는 스킬

120K 토큰 근처에서 성능이 급락하는 문제를 해결한다. 인계·요약·압축.

  • Handoff구조화된 인수인계 문서 생성. 서브에이전트/새 세션에 그대로 넘길 수 있음.
  • Caveman불필요 서술을 제거해 토큰 65% 절감. CLAUDE.md도 -46%까지.
  • Executing Plans계획서를 세션 밖에서 별도 에이전트가 이어받아 실행.
Data · 웹 · 확장

외부 세계와 연결하는 스킬

웹·MCP·크롤링. Claude의 손을 프로젝트 밖 데이터까지 확장한다.

  • FirecrawlJS 렌더 사이트 포함 80%+ 콘텐츠 회수율. 결과를 파일로 저장해 컨텍스트 보호.
  • MCP Builder커스텀 Model Context Protocol 서버를 스킬 지시대로 스캐폴딩.
  • Grill Me계획의 가정·의존을 집요하게 캐물어 사전 정합성을 확보.

04 도입 3단계 · 개인 · 팀 관점

한꺼번에 다 켜면 컨텍스트 예산이 잠식된다. 아래 순서로 3주에 걸쳐 도입해 보고, ROI를 각자 확인한 뒤 팀 표준으로 굳히는 것을 권장.

i.

Week 1 · 프로세스 축 켜기

가장 큰 ROI가 나오는 프로세스 스킬을 먼저 세팅. "코드를 어떻게 짤지"가 아니라 "코드를 시작하기 전에 무엇을 하는지"를 바꾼다.

/plugin marketplace add obra/superpowers-marketplace /plugin install superpowers@superpowers-marketplace
ii.

Week 2 · 시각·문서 축 켜기

대외 산출물이 있는 사람은 Frontend Design과 문서 스킬을. Anthropic 공식 저장소에서 필요한 것만 선택 설치한다.

/skill anthropic-skills:pdf /skill artifact-design
iii.

Week 3 · 팀 표준으로 굳히기

반복 결정은 Skill Creator로 사내 스킬화. 팀 CLAUDE.md에 auto-load 기준을 명시해 세션마다 재현되도록.

/skill anthropic-skills:skill-creator .claude/settings.json → enabledPlugins
